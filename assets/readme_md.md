# INDAM - Aprendizaje Inclusivo de Lengua de Señas

Proyecto desarrollado como trabajo final para la materia **Tecnología de la Información**.

---

## 📌 Descripción

**INDAM** es un sitio web educativo e interactivo orientado a brindar una herramienta accesible para dar los primeros pasos en el aprendizaje de la Lengua de Señas.

El sitio ofrece contenido estructurado didácticamente para aprender señas fundamentales: desde el abecedario dactilológico y la gama de colores principales, hasta expresiones básicas y saludos para entablar una primera conversación con confianza.

---

## 🎯 Objetivo

El proyecto tiene como objetivo desarrollar un sitio web inclusivo y accesible aplicando las buenas prácticas de maquetación en HTML5, estilizado mediante CSS3 y diseño adaptable (responsive design), apoyándose en el uso de Inteligencia Artificial para optimizar el diseño, la experiencia del usuario (UX/UI) y la compatibilidad con múltiples dispositivos.

---

## 🧩 Secciones del Sitio

El sitio está organizado en las siguientes páginas temáticas:

* **Inicio (`index.html`):** Bienvenida general, introducción al proyecto y enlaces de navegación rápida a las secciones principales.
* **Presentación (`presentacion.html`):** Guía visual con señas básicas de saludo y frases iniciales de conversación.
* **Abecedario (`abecedario.html`):** Mapeo dactilológico de cada letra del abecedario en señas.
* **Colores (`colores.html`):** Muestra e ilustración de los colores principales en Lengua de Señas.
* **Contáctanos (`contactanos.html`):** Formulario de contacto directo para realizar consultas o enviar retroalimentación.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Marcado semántico y estructurado de todas las páginas del sitio.
* **CSS3:** Estilos visuales, diseño responsive implementado mediante Flexbox, CSS Grid y Media Queries para asegurar la correcta visualización en pantallas de escritorio, tablets y dispositivos móviles.
* **Google Fonts:** Tipografía *"Quicksand"* (variantes 400, 600, 700) para una estética moderna y de fácil lectura.
* **FontAwesome (v6.5.2):** Librería de iconos vectoriales utilizada en los enlaces de redes sociales del footer.
* **Recursos Gráficos:** Imágenes locales (`.jpg`, `.jpeg`) y vectores SVG (`.svg`) para los iconos de la barra de navegación.

---

## 📱 Diseño Responsive

El sitio cuenta con una maquetación totalmente responsive que adapta el encabezado, los menús de navegación, la grilla de tarjetas (`.cards-grid`), los formularios y el pie de página según la resolución de la pantalla. Se emplearon *breakpoints* a través de CSS Media Queries (`max-width: 768px` y `max-width: 480px`).
